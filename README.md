# WK Store - E-Commerce Landing Page

A modern, fully responsive e-commerce product landing page built with vanilla HTML5, CSS3, and JavaScript.

## 🚀 Live Demo
[View Live Project](https://waqad1.github.io/product-landing-page/)

## ✨ Features
- **Responsive Navigation Header** with brand logo and dynamic cart badge.
- **Interactive Featured Showcase**:
  - Image gallery thumbnail switcher.
  - Dynamic color variation selector with image swap.
  - Quantity selector (+/-).
- **Interactive Slide-Out Cart Drawer**:
  - Add to cart functionality from hero & product grid.
  - Dynamic subtotal calculation.
  - Item removal logic.
- **Product Grid**: Responsive product cards for different categories.
- **Modern Dark Footer**: Complete with quick links and contact info.

## 🛠️ Built With
- **HTML5**: Semantic markup
- **CSS3**: Flexbox, CSS Grid, custom properties, and smooth animations
- **JavaScript (ES6+)**: DOM manipulation and state management
- **Google Fonts**: Poppins
